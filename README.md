Glog는 수업과 회의를 실시간으로 받아쓰고, 번역하고, 요약하는 서비스입니다.

## 기능

- **실시간 받아쓰기** - 말하는 동안 문장이 바로 글로 쌓입니다.
- **자동 번역** - 원어 강의나 회의를 한국어로 따라갈 수 있습니다.
- **AI 요약** - 녹음을 멈추면 내용을 요약해 정리합니다.
- **맥락 학습** - 폴더마다 전문 용어를 익혀 인식 정확도를 높입니다.
- **보관함** - 기록을 폴더별로 저장하고 다시 찾아볼 수 있습니다.

## 사용하기

[glognote.com](https://glognote.com)에서 바로 시작할 수 있습니다.

# Glog

- Live transcription as you speak
- Automatic translation
- AI summaries when recording stops
- Per-folder context learning for domain-specific terms
